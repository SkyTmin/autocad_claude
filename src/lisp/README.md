# src/lisp/ — AutoLISP-исходники

Все команды и утилиты для Civil 3D, написанные на AutoLISP.

## Структура

```
lib/         # Общие утилиты (геометрия, парсинг, обёртки над API)
commands/    # Готовые команды для пользователя (gc-*)
tests/       # Тесты (по мере появления)
```

## Конвенции

- По умолчанию — префикс `gc-` для команд. Короткие алиасы (1–3 буквы)
  допустимы по запросу пользователя (напр., `sv` для часто используемой
  команды). См. `docs/conventions.md`.
- Имена внутренних функций — `kebab-case`.
- Кодировка — UTF-8 без BOM.
- Стиль и подробности — `docs/conventions.md`.

## Загрузка в Civil 3D

```
(load "путь/к/файлу.lsp")
```

Или через диалог `APPLOAD`. Постоянная загрузка — через `acaddoc.lsp`
(когда дойдём до этого этапа — задокументируем отдельно).

### `commands/vid.lsp` — выделение рамкой заданного размера

Команда `VID` заменяет ручное растягивание рамки мышью.

1. **Первый запуск**: спрашивает размер по `Y` (сверху вниз), затем по `X`
   (слева направо). Формат — `5,300` (метры, запятая, миллиметры); точка
   равнозначна запятой, `5,3` = `5,300` = 5.300 м, пробелы игнорируются.
2. Клик задаёт **левый верхний** угол области; рамка растёт вправо и вниз.
3. **Дальше каждый вызов — только клик**: размеры и тип выделения хранятся
   как шаблон до закрытия чертежа.

Опции в строке запроса:

| Опция | Что делает |
|---|---|
| `Размеры` (`Р`) | Перезадать `Y` и `X` |
| `Тип` (`Т`) | Переключить синее ⇄ зелёное выделение |

- **Синее** — только объекты, попавшие целиком. **Зелёное** — всё, чего рамка
  коснулась. Для узкой полосы нужно зелёное: в полосу 30 мм целиком почти
  ничего не влезает, и синее вернёт 1–2 объекта.
- Рамка передаётся четырёхугольником (`ssget "_WP"` / `"_CP"`), поэтому
  **поворачивается вместе с ПСК**. Двухугольный `"_W"` этого не умеет — это
  и был баг v1.
- Результат остаётся выделенным с ручками, геометрия в чертёж не добавляется.

### `commands/sv.lsp` — обработка свай

> Описание ниже отражает первую версию. Актуальное поведение `v16`
> (режим `SV 3`, команда `SVP`, слои, смещения) — в `status/HANDOFF.md`
> и спеках SPEC-003 / SPEC-004.

Одна команда `SV` с двумя режимами:
- **Режим 1** — пользователь выделяет все 11 точек (низ + верх + верхушка)
  одной выборкой; алгоритм сам кластеризует по Z.
- **Режим 2** — пользователь поочерёдно указывает группы.

По выбранным точкам:
1. Для нижнего и верхнего сечений отдельно перебирает все тройки C(N,3),
   строит окружность по 3 точкам, выбирает ту, у которой `|R − 710мм|`
   минимальный.
2. Рисует красную окружность нижнего сечения (`GC-Сваи-Низ`), зелёную
   верхнего (`GC-Сваи-Верх`).
3. От центра нижнего — две стрелки длиной 200 мм по X и Y чертежа,
   направления по знакам (X_верх − X_низ) и (Y_верх − Y_низ).
4. Подписи у концов стрелок: `<NN> мм (<NN> мм/1м)` шрифтом СПДС
   (с fallback'ом на ISOCPEUR/Standard).
5. Сводка в командную строку: координаты центров, радиусы, отклонения,
   `dZ`, превышения допуска (20 мм/1м).

Sample для теста: `samples/csv/2026-05-03-pile-sample-01.csv`. Точки
импортируются в Civil 3D стандартным образом, затем выделяются командой.
