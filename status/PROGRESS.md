- 2026-05-03 — [fix] sv.lsp v2 после первого прогона у Шамиля:
  - кластеризация Z: фиксированный порог 100мм → адаптивная (2 самых больших
    разрыва) — фиксит баг «найдено 4 группы» при разбросе Z
  - длина стрелки 200 → 400 мм; высота текста 300 → 100 мм
  - формат подписи: «NN мм (NN мм/1м)» → одно целое число (мм/1м)
  - позиция текста: X — под серединой стрелки (ротация 0); Y↑ — слева,
    Y↓ — справа, обе с ротацией 90°
  - константы вынесены в начало файла для ручной правки
- 2026-05-03 — [spec] SPEC-001 → v2 с журналом ревизий
- 2026-05-03 — [fix] sv.lsp v3 после второго прогона у Шамиля:
  - `ssget` теперь с фильтром `POINT,AECC*POINT,AEC*POINT` —
    больше не захватывает нарисованные нами объекты (root cause бага
    «4 группы» при повторных запусках)
  - кластеризация переписана: фикс. порог 50 мм + отбор 2 групп
    с максимальным количеством точек (≥3) — устойчиво к посторонним
    точкам в выборке (точно по словам Шамиля «минимум 3 на одной высоте»)
  - X-стрелка влево: текст НАД серединой (было: всегда под) — как в menuGEO
- 2026-05-03 — [spec] SPEC-001 → v3 (новая логика выборки и кластеризации)
- 2026-05-03 — [spec] SPEC-002 «Обработка нескольких свай за раз» — расширение
  режима 1 команды SV: 2-уровневая кластеризация (Z + XY) + сопоставление
  пар низ↔верх. Работает и для 1 сваи, и для N свай в одной выборке.
- 2026-05-03 — [feat] sv.lsp расширен по SPEC-002 v1:
  single-linkage XY-кластеризация + сопоставление пар. **Не сработало** при
  3 сваях (см. фидбек Шамиля со скринами).
- 2026-05-03 — [fix] SPEC-002 → v2: переход с single-linkage на жадный
  поиск окружностей. Root cause: при сваях на 1.5–2.5 м точки разных свай
  в плане ближе друг к другу (~0.1–0.5 м), чем точки одной сваи на крайних
  концах дуги (до 1.4 м) → склейка соседних свай. Новый алгоритм
  привязывается к КОНКРЕТНОМУ центру каждой сваи через окружность R≈710 мм.
- 2026-05-03 — [fix] Положение текста переписано в 4 квадранта по таблице
  Шамиля (через формулу `sxy = sign(dx·dy)`). Новые константы:
  `*gc-pile-text-offset*` (0.4м), `*gc-pile-fit-tol*` (0.05м),
  `*gc-pile-fit-radius-eps*` (0.05м).
