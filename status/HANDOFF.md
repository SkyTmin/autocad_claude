## Что делает `SV`

`SV` — стабильная команда для расчета отклонения сваи по двум сечениям:

- режим `1`: пользователь рамкой выбирает все точки, код сам группирует сваи по XY и сечения по Z;
- режим `2`: пользователь вручную выбирает нижнее и верхнее сечения;
- строятся окружности нижнего и верхнего сечений;
- считается смещение верхнего центра относительно нижнего;
- рисуются стрелки X/Y и подписи в `мм/1м`;
- важное исправление v11: `gc-pile-strip-hm` удаляет пару отметчиков высоты только если она явно изолирована над сечением.

`SV` в рамках v12/v13 не меняли по поведению намеренно.

## Что делает `SVP v13`

`SVP` — команда продления/интерполяции сваи до введенной Z-отметки и расчета проектного отклонения до нового сечения.

Сценарий пользователя:

1. Запустить `SVP`.
2. Выбрать съемочные точки свай рамкой так же, как в `SV` режим `1`.
3. Ввести целевую высотную отметку Z.
4. Выбрать рамкой проектные объекты: `CIRCLE`, `POINT`, `AECC*POINT`, `AEC*POINT`.

Поведение:

- для каждой сваи находятся нижнее и верхнее сечения по текущей логике `SV v11`;
- центр на целевой отметке считается по формуле:

```text
k = (Ztarget - Zlow) / (Zhigh - Zlow)
Xtarget = Xlow + k * (Xhigh - Xlow)
Ytarget = Ylow + k * (Yhigh - Ylow)
Ztarget = введенная отметка
```

- интерполяция и экстраполяция выше/ниже фактической съемки разрешены;
- новое сечение строится окружностью `R = 0.710` на слое `GC-Сваи-Срез`;
- проектный центр для `CIRCLE` берется из центра окружности, для точек — из XY координат;
- Z проектного объекта игнорируется, графика проектного отклонения рисуется на Z среза;
- для каждого нового центра берется ближайший неиспользованный проектный центр в радиусе `*gc-pile-project-match-max* = 2.000` м;
- если ближайший проектный центр дальше 2 м, сечение строится, а проектное отклонение для этой сваи пропускается с сообщением в консоль;
- `dX = Xnew - Xproject`, `dY = Ynew - Yproject`;
- подписи проектного отклонения показываются в целых абсолютных миллиметрах, без деления на метр;
- направление задают стрелки X/Y от проектного центра в сторону нового центра;
- слои проектной графики: `GC-Сваи-Проект-Отклонения`, `GC-Сваи-Проект-Текст`.

Если проектные объекты не выбраны, `SVP` строит только новые сечения, как v12.

## Открытые вопросы и долг

### Открытый issue #001

Свая с недосэмплированным сечением из 2 снятых точек пока не обрабатывается, потому что круг строится только по `>=3` точкам.

Варианты решения:

1. Оставить как рабочее ограничение и просить снимать минимум 3 точки на сечение.
2. Отдельной итерацией добавить построение окружности по 2 точкам + `*gc-pile-r-norm*`.

Вариант 2 требует отдельного ADR/спеки: это геометрическое допущение, а не мелкий фикс. `SVP v13` этот вопрос намеренно не решает.
