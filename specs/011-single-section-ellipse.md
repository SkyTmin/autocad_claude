# SPEC-011: SV 5 — эллипсы сечений по точкам

**Статус**: код написан, расчётные проверки пройдены; Civil 3D проверяет пользователь.
**Дата**: 2026-11-03.
**Запрос**: режим 5, три точки или больше на сечение; подобрать лучший эллипс.
Уточнение: все выбранные высоты обрабатываются за один запуск, цвет от точек.
**Связано**: SPEC-010, ADR-0014. Файл `src/lisp/commands/sv.lsp`, v31.

## Сценарий и результат

SV → 5 → выбрать точки одного или нескольких горизонтальных сечений → Enter.
Принимаются POINT / AECC*POINT / AEC*POINT через существующий фильтр SV.
Точки разделяются по Z с допуском 50 мм от минимального Z группы, затем
по связности в XY с прежним допуском SV 1,8 м. Все уровни сохраняются,
без выбора только нижнего/верхнего и без удаления отметчиков высоты.
Для каждой группы строится отдельный настоящий ELLIPSE на среднем Z,
слой GC-Сваи-SV5-Эллипс. Второй уровень, проект и срез не запрашиваются.
В командную строку выводятся номер сечения, число различных точек,
центр, полуоси, невязка в мм и общий итог построено/пропущено.
Углы и отклонения между сечениями в этом режиме не нужны.
Enter без выборки отменяет; Esc использует общий обработчик SV.

Цвет каждого эллипса берётся из свойства цвета точек его группы:
явный ACI / TrueColor, для ПоСлою — цвет слоя, для ByBlock вне блока — 7.
Если цветов несколько, берётся наиболее частый с сообщением; при
равенстве — первый в группе. Дублированные координаты не увеличивают вес.
Цвет фиксируется на эллипсе независимо от общего слоя эллипсов.
Компонентные переопределения маркера/подписи стилем COGO не читаются:
используется свойство Цвет самого объекта, что сообщается при запуске.

## Подбор

Используется модель SV 4: отношение a/b = sqrt(1+(1/4,5)^2),
номинальная малая полуось R=0,710 м (большая 0,727319618 м).
Эти размеры — ориентир, а не принудительная подмена результата.
По трём точкам произвольный эллипс однозначно определить нельзя:
заданные отношение осей и ориентир радиуса ограничивают выбор.
При 3–4 точках команда сообщает зависимость результата от номинала.

Перебор направлений 0…360° с шагом 5°, затем четыре уточнения шага /5.
Для каждого направления общая функция `gc-pile-e-fit` использует все
различные точки сечения, сжимает большую ось и решает МНК окружности.
Поправка за небольшой разброс Z — как в SV 4. Критерий выбора:
score = radial-RMS² + (b−R)². Берётся лучший из вычисленных кандидатов.
Комбинации троек и отбрасывание неудобных замеров не используются.
Центр/полуоси/поворот выбранного проектного объекта не читаются.

## Ограничения и ошибки

- Минимум три различные неколлинеарные точки; дубликаты с допуском 1e−8
  удаляются. Вырожденная или слишком короткая дуга даёт сообщение без объекта.
- Разброс Z не более 50 мм, иначе просьба выделить одно сечение.
- Группы с менее чем тремя различными точками пропускаются с сообщением;
  остальные сечения продолжают обрабатываться.
- Близкие сваи с расстояниями между точками <=1,8 м могут объединиться:
  в таком случае выбирать их отдельными запусками. Высоты в пределах
  50 мм считаются одним уровнем.
- Невязка >10 мм или отличие b от R >50 мм — прежнее предупреждение SV 4.
- Ошибки чтения COGO, создания слоя и ELLIPSE сообщаются явно.
- Формулы, группировка и сценарии SV 1/2/3/4 и SVP не меняются.

## Данные и приёмка

Реальный пример: `samples/csv/2026-05-03-pile-sample-01.csv`, отдельно
пять нижних точек Z=1,400…1,402 и пять верхних Z=2,397…2,404.
Старые CSV не являются эталоном наклонной сваи; проверяем обработку
каждого сечения и конечность результата, не подгоняем к неизвестному эллипсу.

Расчётные проверки: 3/4 точки, много точек, разные повороты, шум, дуга,
геодезические координаты, дубликаты, все точки влияют на расчёт, вырождение,
плохой Z, пустой выбор, ошибка создания, фильтр POINT/COGO и маршрут меню 5.
Пакет из трёх высот и двух свай, сохранение всех точек с одинаковым Z,
малые/вырожденные группы не мешают остальным. Цвета ACI / TrueColor /
ПоСлою / ByBlock, смешанные цвета и независимость эллипсов на общем слое.
Проверить DXF эллипса и неизменность прежнего набора SV 4.
Кодировка CP1251 без BOM, синтаксис и локальные переменные обязательны.
AutoCAD/Civil 3D не запускаем: визуальную проверку выполняет пользователь.

Проверки выполнены в `node tools/test_sv4.mjs`: 10 вариантов подбора,
все перечисленные ошибки и варианты цвета, шесть эллипсов трёх высот
двух свай, сохранение всех точек одинакового Z. Исходный sample-01 даёт
два эллипса по пяти точкам и пропуск одиночного замера. Меню 1–5,
DXF/отказы создания и прежние регрессии SV 4 проходят.
