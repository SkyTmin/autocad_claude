# Спецификации фич

Это **источник истины** перед написанием кода. Без спеки в этой папке код
не пишется (кроме тривиальных правок ≤5 строк).

## Как писать

1. Скопировать `_template.md` в `NNN-короткое-имя.md` (`NNN` — следующий по порядку).
2. Заполнить все обязательные секции.
3. Согласовать с Шамилем (вопросы — через `AskUserQuestion`).
4. Только после согласования — писать код.

## Структура имени

`NNN-короткое-имя.md`:
- `NNN` — 3-значный порядковый номер (`001`, `002`, …).
- `короткое-имя` — 2–4 слова через дефис, отражает суть.

Примеры: `001-import-csv-points.md`, `002-execute-monolith.md`.

## Связь с ADR

Спека описывает **что** делаем. ADR описывает **почему** именно так
(когда есть архитектурный выбор). Это разные документы.

## Жизнь спеки

- **Активна**: фича в работе или используется.
- **Заморожена**: отложена, причина в `status/BACKLOG.md`.
- **Заменена**: новой спекой; ссылка в обеих сторонах.
- **Отменена**: фича не делается; причина в самой спеке в начале.

Статус указывается в шапке спеки.
