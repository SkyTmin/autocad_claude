# Глоссарий — геодезические термины

Этот файл существует для AI: чтобы нейросеть, не знакомая со строительной геодезией,
понимала контекст. Расширяй по мере появления новых терминов.

---

## Виды работ

**Строительная геодезия** — геодезическое сопровождение строительства. Включает
разбивочные работы (вынос проекта в натуру) и исполнительные съёмки (фиксация
факта построенного).

**Камеральная обработка / "камералка"** — обработка полевых данных в офисе:
импорт измерений, уравнивание, построение чертежей. То, чем занимается Шамиль.

**Исполнительная съёмка / "исполнителька"** — съёмка построенного объекта для
сравнения с проектом. Результат — исполнительный чертёж с фактическими размерами,
координатами, отметками.

**Разбивочный чертёж / разбивочка** — чертёж для выноса проекта в натуру.
Содержит координаты разбивочных осей, отметки, привязки.

**Топографическая съёмка / топосъёмка** — съёмка местности с горизонталями,
ситуацией, условными знаками.

**Межевой план** — кадастровый документ с границами участка, координатами
поворотных точек.

## Объекты строительства (контекст пользователя)

**Монолит** — монолитные железобетонные конструкции (фундамент, стены, перекрытия).
Исполнительная съёмка по монолиту: отметки верха/низа, отклонения от проекта,
геометрия.

**Сваи** — свайное основание. Исполнительная съёмка свай: координаты центров,
отметки верха, отклонения от проектного положения, длины.

**Дороги** — линейные объекты. Съёмки: проекция оси, поперечники, продольники,
бордюры, разметка, искусственные сооружения.

## Измерительные приборы

**Тахеометр** — оптический прибор для измерения углов, расстояний, координат.
Выгрузка: txt, csv, sdr, gsi.

**GNSS-приёмник** — спутниковая геодезия. Координаты в WGS-84/местной системе.
Выгрузка: csv, txt, RINEX.

**Нивелир** — измерение превышений (отметок).

## Координаты и системы

**МСК** — местная система координат (например, МСК-77 для Москвы).
**WGS-84** — глобальная.
**Балтийская система высот (БСВ)** — основная система высот в РФ.
**Условная система** — локальная для стройплощадки (часто 0,0,0 — угол здания).

**Поворотная точка** — вершина границы (участка/контура).

## Стандарты

**ГОСТ Р 21.101** — основные требования к проектной документации.
**ГОСТ 21.501** — правила выполнения архитектурно-строительных рабочих чертежей.
**СПДС** — система проектной документации для строительства.
**ГОСТ Р 21.1101-2020** — правила оформления.

Имена слоёв, стили текста, штампы, рамки — всё регламентировано.

## Civil 3D-специфичное

**COGO Point** — точка с координатами, описанием, кодом. Базовый объект Civil 3D
для съёмки.

**Surface** — цифровая модель поверхности (TIN/grid).

**Alignment** — трасса (ось линейного объекта).

**Profile** — продольный профиль вдоль трассы.

**Sample Line** — линия для построения поперечников.

**Pipe Network** — сеть трубопроводов.

## Форматы файлов

| Формат | Что |
|---|---|
| `.dwg` | основной формат AutoCAD |
| `.dxf` | обмен между CAD-системами |
| `.csv` | таблицы координат, ведомости |
| `.txt` | выгрузки с приборов (часто `№ X Y Z описание`) |
| `.sdr` | формат Sokkia |
| `.gsi` | формат Leica |
| `.kml/.kmz` | Google Earth |

## Аббревиатуры в речи

- **ИГС** — исполнительная геодезическая схема
- **СПДС** — см. выше
- **ОГГ** — отдел главного геодезиста
- **ППР** — проект производства работ
- **ПОС** — проект организации строительства
