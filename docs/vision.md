# Видение проекта

## Проблема

Шамиль — геодезист-камеральщик, выполняет много **похожих** чертежей в строительной
геодезии (исполнительные съёмки монолита/свай/дорог, разбивочные чертежи). Содержание
почти одинаковое — меняются только **значения**: координаты, отметки, размеры,
номера осей. Ручное вычерчивание повторяющейся графики занимает основное время и
склонно к ошибкам копипасты.

## Цель

Сократить время на типовой чертёж за счёт автоматизации повторяющихся операций
в Civil 3D через AutoLISP-команды и внешнюю обвязку (Python/.NET) для подготовки
данных.

## Пользователь

- **Один пользователь**: Шамиль. Не программист.
- **Среда**: Windows + AutoCAD Civil 3D.
- **Источники данных**: Excel/CSV, выгрузки с тахеометров и GNSS (txt/sdr),
  готовые DWG-шаблоны, ручной ввод.

## Метрики успеха

| Метрика | Цель |
|---|---|
| Время на типовой исполнительный чертёж | сократить ≥ в 2 раза |
| Кол-во ручных операций для повторяющегося чертежа | свести к 1–3 командам |
| Кол-во ошибок копипасты | свести к нулю |
| Время на онбординг новой AI-сессии в проект | ≤ 5 минут чтения |

## Не в scope

- Универсальный CAD-фреймворк
- Поддержка чертежей вне строительной геодезии без явного запроса
- Облачные сервисы / SaaS
- Мобильные приложения
- Замена Civil 3D или Excel — мы их **дополняем**, не заменяем

## Принципы

1. **Инструмент должен экономить минуты с первого использования** — никаких "сначала настрой 100 параметров".
2. **Данные — первичны, код — вторичен**. Сначала смотрим реальные `samples/`, потом пишем код.
3. **Лучше одна работающая команда, чем десять заглушек.** Качество > количество.
4. **Документация = код первого класса.** Без обновления `HANDOFF.md` фича не закрыта.
