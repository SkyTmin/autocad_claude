# ADR-0015: Геометрический подбор SV 4/5 с номиналом в расчёте

**Дата**: 2026-11-12. **Статус**: заменён ADR-0016 по уточнению пользователя.
Уточняет расчёт ADR-0010/0014, SPEC-010/011. Причины: issues #012–014.

## Решение

Для заданного угла минимизировать геометрический критерий, а не только
алгебраическую ошибку окружности. Неизвестные: центр и малая полуось
каждого сечения. Отношение осей остаётся заданным наклоном 1:4,5.
Все различные точки участвуют с одинаковым весом; номинал 0,710 м
входит непосредственно в нормальные уравнения. В SV 4 оба сечения
уточняются совместно с существующим штрафом поперечного/обратного сдвига.

Применить демпфированный метод Гаусса–Ньютона с проверкой убывания полного
критерия. Исходные координаты центрировать до расчётов. Начальные варианты:
алгебраическая окружность и её масштабирование к номиналу; выбирается
лучший результат уточнения. Отрицательные радиусы не допускаются.

По углу проверить весь оборот и уточнить каждый локальный минимум
грубой сетки, включая минимум через границу 0/360°. Знак поправки за
разброс Z сохраняется. Точное решение входит в допустимую модель; конечная
численная точность и короткая дуга не дают гарантии уникальности результата.

Для SV 4 сортировать Z с уникальным индексом, как уже делает SV 5.
Не удалять точки по эвристике двух верхних отметок внутри допустимого
разброса 50 мм: обычная съёмка наклонного цилиндра имеет такое же распределение.
Самостоятельные группы из одной/двух точек не образуют сечение.

## Альтернативы

Более мелкая сетка вокруг одного минимума не устраняет ошибку выбора
самого минимума. Один штраф после свободного МНК не меняет центр/размер.
Принудительные полуоси независимо от точек скрывают несовпадение съёмки.
Отбор удачной тройки по близости к номиналу может скрыть остальные замеры;
он не вводится без критерия допустимости исключённых точек.

## Последствия и проверка

Расчёт дороже прежнего, но число неизвестных всего 3/6, без перебора
всех троек и без внешних зависимостей. Контрольные ошибки из ревью должны
перестать воспроизводиться. Проверяются короткие дуги, шум, точный номинал,
существенно иной фактический размер, равные Z, миллионные координаты,
цвета, срезы, проектные отклонения и прежние CSV. Civil 3D проверяется вручную.
