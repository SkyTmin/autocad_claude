# ADR-0010: Подбор эллипсов наклонной сваи в SV 4

**Дата**: 2026-11-02. **Статус**: принято для SPEC-010.

## Контекст

Шамиль запросил горизонтальные эллиптические сечения сваи R=0,710 м,
наклон 1 м по горизонтали на 4,5 м по вертикали. Нужно найти направление
по съёмке и сравнить центры. Точек может быть много, включая неполную дугу.

## Решение

Самодостаточный src/lisp/commands/sv.lsp, без новых зависимостей CAD.
Отношение полуосей задаётся известным наклоном. Для каждого направления
сжимаем большую ось и решаем МНК окружности по всем точкам. Координаты
центрируются перед вычислением моментов для устойчивости на миллионных XY.
Направление общее для обоих сечений, выбирается сеточным перебором с
уточнением. В критерии участвуют невязка, близость радиусов к 0,710 м и
поперечная составляющая линии центров. Номинал служит ориентиром, а найденные
радиусы и невязки сообщаются пользователю. Выбросы не удаляются молча.
Разброс Z внутри сечения исправляется переносом по номинальной оси к среднему Z.

## Альтернативы

Свободная коника требует минимум пяти точек, на короткой дуге неустойчива,
не использует известную геометрию цилиндра. Полный перебор троек с проверкой
каждого результата на всех точках растёт как N^4. Подбор по всем точкам
для фиксированного числа направлений растёт линейно; удаление точных
дубликатов и существующая XY-группировка остаются квадратичными.

## Последствия

Форма рассчитана для заданного наклона 1:4,5; фактический наклон центров
выводится отдельно. Это не проверка отклонения от проектного азимута.
Автогруппировка сохраняет предел XY 1,8 м; есть ручной выбор сечений для
больших разносов и близких свай. При трёх точках вычисление возможно,
но независимой оценки ошибки съёмки недостаточно — нужна проверка на чертеже.
AutoCAD/Civil 3D проверяет пользователь; математические проверки не заменяют CAD.
