# ADR-0014: Подбор эллипсов отдельных сечений в SV 5

**Дата**: 2026-11-03. **Статус**: принято по запросу режима 5.

## Контекст

Нужно построить эллипс одного сечения по трём и более точкам, с тем же
подбором, что в SV 4. Второго сечения для определения оси сваи нет.
Произвольный эллипс имеет пять параметров и по трём точкам неоднозначен.

## Решение

Повторно используем `gc-pile-e-fit` с заданным отношением полуосей SV 4.
Среди направлений выбираем минимум суммы квадратов невязки и отличия
малой полуоси от номинальных 0,710 м. Парный штраф направления центров
из SV 4 здесь не применяется. Все различные точки входят в каждую
оценку; радиус не зажимается в норматив. При 3–4 точках явно сообщаем,
что выбор зависит от номинальных размеров. Даже такой подбор не даёт
гарантии единственного физического решения по редкой/короткой дуге.

Отдельный пункт 5 общего меню SV. По уточнению пользователя один выбор
может содержать несколько сечений: сначала группируем по Z (разброс
до 50 мм), затем по связности XY (1,8 м). Каждое сечение независимо,
включая промежуточные высоты и несколько свай; пары не формируются.
Сортировка по Z с уникальным индексом для равенств сохраняет все точки
одной отметки и не требует повторного поиска записей через nth.
Собственный слой GC-Сваи-SV5-Эллипс, средний Z каждого сечения.
Цвет задан на каждом эллипсе по точкам: ACI/TrueColor или разрешённый
цвет слоя для ByLayer. Несколько цветов — большинство с сообщением,
равенство — первый в группе. Дубликаты координат не добавляют голосов.
Переопределения отображения компонентов COGO-стилем не считываются;
используется свойство Цвет точки, а не отдельно цвет маркера/подписи.
Проект, срез, второе сечение и схема угла не запрашиваются.
Старые режимы не меняются.

## Альтернативы и последствия

Свободная аппроксимация пяти параметров потребовала бы минимум пяти
точек и нарушила бы запрос про три. Перебор троек теряет информацию
остальных измерений. Привязка к выбранному проектному эллипсу потребовала
бы дополнительного ввода и является отдельной задачей.

Действуют ограничения модели SV 4: отношение осей задано заранее,
направления ищутся дискретно с уточнением; глобальный минимум среди всех
возможных произвольных эллипсов не обещается. Проверки — численные и DXF;
отрисовку в Civil 3D проверяет пользователь.
