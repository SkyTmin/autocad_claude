# Конвенции

Правила, которым код, документация и чертежи следуют единым целым.

---

## Документация (`*.md`)

- Язык: русский.
- Заголовки: `#`, `##`, `###` (без `####+` без необходимости).
- Списки: `-` для маркеров, `1.` для нумерации.
- Таблицы — для сравнений 2+ вариантов.
- Длина файла: ≤ 300 строк (длинные дробить).
- Каждый файл начинается с одного `#`-заголовка.

---

## Спецификации (`specs/`)

- Имя: `NNN-короткое-имя.md`, где `NNN` — порядковый номер (`001`, `002`, …).
- Один файл = одна фича.
- Шаблон: `specs/_template.md`.
- Спека пишется **до** кода.

---

## ADR (`docs/decisions/`)

- Имя: `NNNN-краткое-имя.md`, `NNNN` — 4-значный.
- Структура: Контекст → Решение → Альтернативы → Последствия.
- ADR не правится "по месту" — новое решение = новый ADR со ссылкой на старый.

---

## Код AutoLISP

### Имена

- Функции и переменные: `kebab-case`. `make-grid`, `csv->points`.
- Внутренние (private): префикс `--`. `--parse-line`.
- **Команды для пользователя по умолчанию** — префикс проекта `gc-`
  (geodesy-claude). `gc-import-csv`. Защищает от конфликтов с другими
  LISP-наборами.
- **Короткие алиасы (1–3 буквы)** допустимы для часто используемых команд
  по запросу Шамиля. Реализуются как `(defun c:sv ...)`, плюс полное
  имя через `(defun c:gc-pile-process ...)` (или внутренняя функция).
  В шапке файла обязательно указать оба имени.
- Глобальные переменные: окружены `*`. `*default-layer*`.

### Структура файла

```lisp
;;; <имя-файла>.lsp
;;; Назначение: <одна строка>
;;; Зависимости: <если есть>

(defun gc-команда ( / локальные )
  ...
)

(princ "\nЗагружено: gc-команда")
(princ)
```

### Стиль

- Один `defun` = одна логическая операция.
- Локальные переменные — через `/` в списке аргументов.
- Сообщения пользователю — на русском, через `princ` / `prompt`.
- Ошибки — через `*error*` или `vl-catch-all-apply`.

### Кодировка

Файлы `.lsp` — **CP1251 (windows-1251), без BOM**. Не UTF-8: на старых
версиях AutoCAD UTF-8 читается как ANSI и русский текст превращается в кашу.
Обоснование — [ADR-0004](decisions/0004-lisp-files-cp1251.md).
Символы вне CP1251 (`≥`, `×`, `⇄`, `…`) в коде запрещены — только ASCII-замены.

Документация `.md` остаётся в UTF-8.

### Комментарии

- Объясняют **ПОЧЕМУ**, не **ЧТО**.
- Однострочные: `;`. Блочные: `;;`.

## Код Python (когда появится)

- Версия: Python 3.11+.
- Форматирование: `ruff format` (88 колонок).
- Линтер: `ruff check`.
- Имена: `snake_case` для функций/переменных, `PascalCase` для классов.
- Type hints — обязательны для публичных функций.
- Docstrings — на русском, формат Google.

## Имена файлов

- `kebab-case` или `snake_case` — выберем при первом коде, пока единообразие важнее выбора.
- Никакой кириллицы в именах файлов кода (`src/`, `samples/`).
- В `samples/` имена пользователя сохраняем как есть, даже если кириллица.

## Git

- Ветка разработки: `claude/autocad-knowledge-hyVpn` (для AI-сессий).
- Сообщения коммитов: на русском, формат `тип: описание`.
- Типы: `feat`, `fix`, `docs`, `refactor`, `chore`, `spec`, `adr`.
- Один коммит = одна логическая единица.
- Не коммитить: `.bak`, `.tmp`, временные DWG, секреты.

`.gitignore` поддерживается актуальным.
