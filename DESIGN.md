# Lintly — Daily Fluff Tracker

Дизайн-спецификация маленькой ежедневной браузерной игры о коллекционировании пуха/катышков из пупка. Документ ориентирован на разработчика (Codex), который будет реализовывать игру в стеке **Vite + React + TypeScript**.

Документ намеренно описывает только дизайн, поведение, состояния, копирайт и структуру. Кода здесь нет — только псевдоструктуры данных и нотация компонентов.

## 2. Pitch

> **Lintly — это ежедневный коллекционный ритуал.** Раз в день вы залезаете «в пупок», вытаскиваете оттуда катышек или ворсинку, а игра считает находки, ведёт streak и собирает коллекцию из 15 видов пуха — от обычного серого катышка до легендарного «пупкового артефакта».

Жанр: incremental / daily tracker / clicker-collector.
Сессия: 30–90 секунд в день.
Платформа: mobile-first web (PWA-готовая, но не обязательно).

## 3. Визуальный стиль

### 3.1 Настроение

- **Уютный, тёплый, чуть-чуть странный.** Палитра как у тёплого свитера в воскресенье.
- **Юмор сухой и абсурдный**, без физиологичности и грязи. Никаких реалистичных рендеров живота. Только стилизованные формы и метафоры.
- Эстетика близка к Pou + Animal Crossing + страничка из бумажного дневника.

### 3.2 Цветовая палитра

Использовать как CSS-переменные.

| Токен | HEX | Назначение |
|-------|-----|------------|
| `--bg-cream` | `#FBF1E2` | основной фон |
| `--bg-warm` | `#F2E3CB` | вторичный фон, карточки |
| `--skin-light` | `#FFD4B5` | блик на «животе» |
| `--skin-mid` | `#F5B58C` | основной тон «живота» |
| `--skin-shadow` | `#C98966` | тень |
| `--navel-deep` | `#5B3B25` | «глубина» пупка |
| `--ink` | `#2B1F16` | основной текст |
| `--ink-soft` | `#6B5949` | вторичный текст |
| `--accent-rose` | `#E89AA5` | акцент UI, кнопки |
| `--accent-sage` | `#8FB89B` | вторичный акцент, успех |
| `--rarity-common` | `#9A9A9A` | обычный |
| `--rarity-uncommon` | `#7DAEC8` | необычный |
| `--rarity-rare` | `#A480D8` | редкий |
| `--rarity-epic` | `#E0894A` | эпический |
| `--rarity-legendary` | `#E5C158` | легендарный |

Градиенты — только мягкие и редко (на кнопке «Покопаться», на rarity badge, на splash).

### 3.3 Типографика

Все шрифты — бесплатные Google Fonts.

- **Display / заголовки**: `Fredoka` (700) — округлый, тёплый.
- **Текст / интерфейс**: `Nunito` (400/600/800) — нейтральный, отлично читается.
- **Числа / счётчик**: `Fredoka` (700) с tabular-nums, чтобы счётчик не «прыгал».

Размеры (mobile baseline):

| Роль | Размер | Вес |
|------|--------|-----|
| H1 | 28px | 700 |
| H2 | 22px | 700 |
| Body | 16px | 400 |
| Caption | 13px | 600 |
| Counter big | 48–64px | 700 |

### 3.4 Формы

- Все радиусы скруглений: `12px` (карточки), `20px` (модалки), `999px` (бейджи и пилюли).
- Тени мягкие: `0 8px 24px rgba(91, 59, 37, 0.08)`.
- «Живот» и пух — органичные blobby формы через SVG path или CSS `border-radius: 50% 45% 55% 50%`.
- Никаких острых углов и тонких линий <1.5px.
- Шум/текстура — CSS `background-image` с тонким noise PNG/SVG-data-uri или `filter: url(#noise)`.

### 3.5 Уровень юмора

- Юмор живёт в **названиях, описаниях и микрокопирайте**.
- В графике — нейтральный, минималистичный.
- Никаких иллюстраций пупка крупным планом, никакого реализма. «Живот» = большое мягкое пятно с маленьким углублением и подсветкой.

## 4. Главный экран (Today)

Главный экран — единственный, на который игрок попадает по умолчанию.

### Структура (сверху вниз, mobile)

1. **Top bar**
   - слева: маленькая «капля пуха» (логотип) + название «Lintly»
   - справа: streak meter (огонёк + число дней)
2. **Big counter**
   - крупное число — общий «вес» пуха за всё время в условных миллиграммах (`mg`)
   - под ним подпись: «накоплено пуха»
3. **Interactive zone — “живот”**
   - центральная зона: ~ 70% ширины контейнера, квадратная.
   - стилизованный «живот» (мягкий пятиугольник/blob с градиентом skin-light → skin-mid → skin-shadow), в центре — углубление пупка (`--navel-deep`).
   - вокруг небольшие декоративные ворсинки (SVG, не интерактивные), они качаются на простой CSS-анимации.
   - подсказка: «Тапните, чтобы покопаться» (исчезает после первого взаимодействия).
4. **Action button**
   - под зоной интеракции, на случай если игрок не понял жест: большая кнопка «Покопаться сегодня» (`--accent-rose`).
   - после ежедневной добычи превращается в «Готово на сегодня · вернуться завтра».
5. **Today preview strip**
   - горизонтальная полоса с миниатюрами того, что найдено сегодня (3–5 шт.).
   - до взаимодействия — три плейсхолдера-«?».
6. **Bottom navigation** (5 пунктов):
   - Today · Collection · Calendar · Achievements · Stats
   - Settings прячется внутри Stats или в иконку «шестерёнка» в top bar.

### Поведение

- Игрок доступен **одной полноценной добыче в день** (по локальной полуночи).
- Если он уже добыл сегодня — зона визуально «успокаивается», кнопка disabled, но можно открыть **Daily Result Modal** снова через тап по зоне.
- Streak обновляется в конце добычи.

## 5. Список экранов

### 5.1 Today — главный экран

См. раздел 4.

### 5.2 Collection — коллекция

- Сетка 3 столбца (mobile), 5 столбцов (desktop).
- Каждая ячейка — карточка `FindingCard`:
  - найденные виды показаны цветной иконкой и названием
  - ненайденные — серым силуэтом и «???»
- Под сеткой: прогресс «открыто X из 15» + `ProgressBar`.
- Тап по ячейке → модалка с описанием, редкостью, датой первой находки, сколько раз найдено.

### 5.3 Calendar — календарь находок

- Месячная сетка 7×N.
- Каждый день — кружок:
  - пустой = не заходил
  - точка = заходил, но без пуха
  - 1–3 цветные точки = редкости находок этого дня
  - корона = в этот день впервые нашёл что-то новое
- Свайп / стрелки для перехода между месяцами.
- Тап по дню → bottom sheet с тем, что найдено в этот день.

### 5.4 Achievements — достижения

- Список карточек, разделённых на «получено» и «в процессе».
- Карточка: иконка + название + краткое описание + `ProgressBar` (например, «5 / 7 дней»).
- Полученные — цветные, неполученные — приглушённые.

### 5.5 Stats — статистика

- Карточки:
  - всего пуха (mg)
  - всего находок (шт)
  - текущий streak / лучший streak
  - редчайшая находка
  - средний вес ежедневной добычи
- Простой бар-чарт за 30 дней (SVG, без библиотеки).
- Распределение редкости — donut chart (опционально, SVG-конический градиент).

### 5.6 Settings — настройки

- Звук: on/off
- Хаптика (vibrate on extract): on/off
- Тема: авто / светлая / тёплая
- Локаль: RU / EN
- «Сбросить всю статистику» (с подтверждением)
- Версия и ссылка на «About»

## 6. Компоненты интерфейса

Каждый описан как набор props и состояний, не как код.

### 6.1 `FluffCounter`

- Большой счётчик, единица — `mg`.
- Props: `value: number`, `unit?: 'mg' | 'g'`.
- Авто-форматирование: `1234` → `1 234 mg`; при `≥1000g` показывает `1.2 kg`.
- При увеличении — короткая анимация «вверх с лёгким bounce» (translateY + opacity).

### 6.2 `StreakMeter`

- Иконка `Flame` (lucide-react), число справа.
- Цвет градиентный по длине streak:
  - 0–2 дней: серый
  - 3–6: розовый
  - 7+: оранжевый
  - 30+: золотой с лёгким glow.
- Tooltip: «X дней подряд».

### 6.3 `FindingCard`

- 3 размера: `xs` (preview strip), `md` (collection grid), `lg` (modal).
- Состояния:
  - `discovered` (цветная иконка, имя, rarity badge)
  - `undiscovered` (серый силуэт, «???»)
  - `new` (цветной + бейдж «NEW» сверху-справа, легчайшая анимация пульсации)

### 6.4 `RarityBadge`

- Пилюля 999px, фон по токену редкости.
- Текст: COMMON / UNCOMMON / RARE / EPIC / LEGENDARY.
- В русской локали: ОБЫЧНЫЙ / НЕОБЫЧНЫЙ / РЕДКИЙ / ЭПИЧЕСКИЙ / ЛЕГЕНДАРНЫЙ.
- Для LEGENDARY — тонкий shimmer-эффект через CSS keyframes (move gradient).

### 6.5 `ProgressBar`

- Высота 8px, скругление 999px, фон `--bg-warm`.
- Заливка цветом в зависимости от контекста (rose / sage / rarity).
- Лейбл `X / Y` справа над баром.

### 6.6 `DailyResultModal`

- Вызывается после завершения добычи.
- Структура:
  - заголовок: «Сегодняшняя добыча»
  - список из 1–N карточек `FindingCard md` с появлением по очереди (`stagger 80ms`)
  - суммарный вес: `+ XX mg`
  - кнопка «Отлично!» — закрывает модалку.
- Если попался редкий — дополнительный layer фейерверка из 8–12 SVG-частиц.

### 6.7 `AchievementToast`

- Появляется снизу (mobile) или справа-снизу (desktop).
- Размер: ширина min(360px, calc(100% - 32px)).
- Структура: иконка + название + «Достижение разблокировано».
- Авто-закрытие через 4.5s, можно swipe-dismiss.
- При нескольких достижениях подряд — очередь, не стек.

### 6.8 Empty states

| Экран | Иллюстрация | Заголовок | Подзаголовок | CTA |
|-------|-------------|-----------|--------------|-----|
| Today (новый игрок) | мягкое пятно + «?» | «Тут ещё чисто.» | «Тапните по пупку — посмотрим, что найдётся.» | «Покопаться» |

| Achievements (пусто) | силуэт медали | «Достижений пока нет.» | «Они придут сами, обещаем.» | — |

## 7. Механика «достать пух»

Три варианта взаимодействия, все реализуются на React без сторонних библиотек анимации.

### Вариант A — `Tap to dig` *(рекомендуется как основной)*

- Игрок тапает на «пупок» 5–10 раз.
- Каждый тап:
  - даёт лёгкий хаптик (`navigator.vibrate(10)`)
  - запускает CSS-анимацию «вмятины» (`scale(0.96)` + `inset shadow`)
  - подбрасывает маленькую SVG-ворсинку у края (parallax-ish)
- На случайном тапе (по seed-вероятности) пух «выходит наружу»: SVG-частица всплывает из пупка, поворачивается и падает в карточку находки.
- После 1–3 успешных находок — открывается `DailyResultModal`.

**Плюсы**: дешёво, тактильно, ясно.

### Вариант B — `Scratch` / drag-gesture

- Игрок зажимает палец и водит по поверхности «живота».
- Прогресс-кольцо вокруг пупка заполняется на основе пройденного расстояния (`pointermove` + накапливаемый `length`).
- При заполнении — выскакивает находка.
- Полоса сбрасывается, можно «начесать» ещё 1–2 находки.

**Плюсы**: ощущается «руками», физичнее.
**Минусы**: на мобильных конфликтует со скроллом — нужно `touch-action: none` на зоне.

### Вариант C — `Hold & release` (gauge)

- Игрок зажимает кнопку «Тянуть».
- Появляется горизонтальная шкала с движущимся индикатором и зелёной зоной.
- Отпустить нужно в зелёной зоне → редкость и вес зависят от точности.
- 1 попытка в день.

**Плюсы**: создаёт мини-навык.
**Минусы**: одноразовое ощущение, быстро надоедает.

### Рекомендация

Сделать **A как основной** и оставить hooks/абстракции, чтобы в будущем можно было докинуть B как «продвинутый режим» в Settings.

## 8. Система редкости и 15 видов пуха

### 8.1 Веса редкости при одном пулле

| Редкость | Шанс | Цвет |
|----------|------|------|
| COMMON | 58% | `--rarity-common` |
| UNCOMMON | 25% | `--rarity-uncommon` |
| RARE | 12% | `--rarity-rare` |
| EPIC | 4% | `--rarity-epic` |
| LEGENDARY | 1% | `--rarity-legendary` |

Pity-механика: если игрок 14 дней подряд не получал ничего выше Common — следующий пулл гарантированно ≥ Uncommon. Если 30 дней без Rare+ — гарантированный Rare.

Daily streak бонус: на 7-й, 14-й, 30-й день — дополнительный пулл с одноразово удвоенными шансами на редкое.

- 1–2 акцентных пятна или ниточки
- цвет — токен редкости + индивидуальный hue-shift

Стиль одинаковый для всех 15, чтобы коллекция выглядела целостно.

## 10. Микрокопирайтинг (RU)

## 11. Responsive layout

### 11.1 Mobile (≤640px) — baseline

- Контейнер: `width: 100%`, `max-width: 480px`, `padding: 16px`.
- Single column.
- Top bar: 56px высотой, sticky.
- Big counter: `font-size: clamp(40px, 12vw, 64px)`, центрирован.
- Interactive zone: `aspect-ratio: 1 / 1`, ширина `min(80vw, 360px)`.
- Bottom nav: fixed, 64px высотой, safe-area-inset-bottom учтена.
- Модалки: full-width, padding 16px, центрированы по вертикали.

### 11.2 Tablet (641–1024px)

- Контейнер расширяется до `560px`, всё ещё одна колонка.
- Bottom nav остаётся снизу.
- Шрифты +1 шаг.

### 11.3 Desktop (≥1025px)

- Две колонки в layout:
  - **Левая колонка** (320px): вертикальный навигационный rail вместо bottom-nav, лого вверху.
  - **Центральная колонка** (max 560px): сам экран Today.
  - **Правая колонка** (320px): «Сегодняшние находки» крупно + текущий streak + последнее достижение.
- При width ≥ 1280px: центральная колонка расширяется до 640px.
- Модалки: max 560px, центрированы.

### 11.4 Универсальные правила

- Минимальные тач-таргеты: 44×44 px.
- Контраст текста к фону: ≥ 4.5:1 для body, ≥ 3:1 для крупного текста.
- Темы: `prefers-color-scheme` поддерживается, но «тёмная» в этой игре — это «warm dark» (бордово-коричневые тёплые тона), не серый чёрный.
- `prefers-reduced-motion: reduce` — отключает все ambient-анимации, оставляет только feedback-анимации длиной ≤ 150ms.

### 12.3 Глобальный state (Zustand store)

Псевдоструктура:

```ts
type State = {

  totalCount: number;
  streak: { current: number; best: number; lastPlayedISO: string | null };
```

### 12.4 localStorage

- Один ключ: `lintly:v1`.
- Сохранять весь стор JSON-stringify после каждой мутации (debounce 300ms).
- При старте — `JSON.parse` с миграцией: если ключа нет → инициализировать дефолт.
- Версионирование: `lintly:v1` → если позже сменится схема, делать `v2` с миграцией.

### 12.5 Daily gate (одна добыча в день)

- Локальная полночь, не UTC: `startOfDay(new Date())` (date-fns).
- В сторе хранится `lastPlayedISO`.
- Хук `useDailyGate()` отдаёт:
  - `canPlay: boolean`
  - `nextResetMs: number` (для тоста «Возвращайтесь через X часов»)
  - `forcePlay()` — dev-only, можно за флагом.

### 12.6 Roll-логика добычи

- Чистая функция `rollDailyLoot(state, rng)` возвращает массив 1–3 находок.
- RNG — обычный `Math.random`, но завязан на seed `dateISO + lastPlayedISO`, чтобы при перезагрузке страницы тот же день не пере-роллил иной результат.
- Учитывает pity и streak-бонусы.
- Возвращает immutable объект, store применяет его через единый reducer-action `applyDailyLoot`.

### 12.7 Достижения

- Каждое — чистая функция-предикат `(state) => boolean | progress`.
- После каждого мутирующего действия — прогоняется `evaluateAchievements(state)`.
- Новые разблокировки кладутся в очередь тостов.
- Очередь тостов — отдельный store-slice, чтобы не блокировать UI.

### 12.8 Анимации (безопасный набор)

Все анимации — CSS, длительность ≤ 400ms, кроме ambient-плавания ворсинок.

- **Тап-вмятина**: `transform: scale(0.96)`, `transition: 120ms ease-out`.
- **Появление пуха из пупка**: keyframe `translateY(0) scale(0.6) opacity 0` → `translateY(-40px) scale(1) opacity 1`, длительность 360ms, easing `cubic-bezier(.2,.7,.2,1)`.
- **Карточка находки появляется в модалке**: opacity 0→1, translateY 8→0, длительность 220ms, stagger 80ms по index.
- **Achievement toast**: slide-up + opacity, 240ms.
- **Legendary shimmer**: бесконечный keyframe `background-position 0% → 200%`, 3s linear. Отключается при `prefers-reduced-motion`.
- **Streak огонёк**: subtle scale 1 ↔ 1.05 на 1.2s ease-in-out при streak ≥ 7.

Никаких сложных физических симуляций. Никаких WebGL.

### 12.9 SVG и иллюстрации

- 15 иконок видов пуха — отдельные `.svg` в `assets/icons/`, импортируются как React-компоненты через `?react` (vite-plugin-svgr) или как URL.
- Каждая ≤ 2 KB, viewBox 0 0 64 64.
- «Живот» на главном экране — один inline-SVG в `Today.tsx`, чтобы реактивно подсвечивать пупок через классы.
- Текстура шума: одна data-uri в CSS-переменной `--noise`, использовать как `background-image` с `mix-blend-mode: multiply` и низкой opacity.

### 12.10 Звук (опционально)

- 3 коротких сэмпла (`.mp3` ≤ 8 KB каждый):
  - `tap.mp3` — мягкий tick
  - `pop.mp3` — pop при находке
  - `chime.mp3` — короткий chime на Rare+
- Включается только если `settings.sound === true` и после первого user-interaction (autoplay policy).

### 12.11 Хаптика

- Только мобильные: `if ('vibrate' in navigator && settings.haptics) navigator.vibrate(10)`.
- При Legendary — паттерн `[15, 40, 15]`.
- Отключаемо в настройках.

### 12.12 Доступность

- Все интерактивные элементы — `<button>` либо `role="button"` с `tabindex` и поддержкой Enter/Space.
- aria-labels на все иконочные кнопки.
- Модалки — фокус-trap, `aria-modal="true"`, закрытие по Esc.
- Контраст и `reduced-motion` — см. раздел 11.4.

### 12.13 i18n

- Простой объект-словарь, два языка: ru/en.
- Хранится в `i18n/`.
- Хук `useT()` возвращает `t(key, params)`.
- Дефолт — ru.

### 12.14 PWA (необязательно для MVP)

- `vite-plugin-pwa` для манифеста и SW.
