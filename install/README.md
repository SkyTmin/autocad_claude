# Установка и обновление

## Установка — один файл, один раз

1. Скачать [`install.bat`](install.bat) (кнопка **Raw**, затем «Сохранить как»).
2. Запустить двойным кликом.

Он сам создаст папку, скачает команды, соберёт модуль `.NET` и пропишет
автозагрузку. Visual Studio и SDK от Autodesk не нужны — компилятор входит
в состав Windows, а библиотеки берутся из папки установленного Civil 3D.

Ставится сюда:

```
%APPDATA%\Autodesk\ApplicationPlugins\GeoClaude.bundle\
    PackageContents.xml          — описание пакета, по нему CAD грузит всё сам
    Contents\lisp\*.lsp          — команды
    Contents\net\GcSurface.dll   — модуль .NET (необязательный)
```

После этого **`APPLOAD` и `NETLOAD` руками больше не нужны**: команды
загружаются при запуске Civil 3D.

## Обновление — одна команда

В командной строке Civil 3D:

```
GCU
```

Скачивает свежие `.lsp` с GitHub и перезагружает их. **Перезапускать CAD
не нужно**: `.lsp` перечитывается на лету.

| Команда | Что делает |
|---|---|
| `GCU` | обновить команды с GitHub и перезагрузить |
| `GCV` | показать, что лежит на диске и загружен ли модуль `.NET` |
| `GCDIR` | сменить папку, если команды лежат не там, куда ставил установщик |

`GCU` и `GCV` работают и в русской раскладке: `ПЕГ` и `ПЕМ`.

## Почему обновление не требует перезапуска

Вся логика живёт в `.lsp`, а он перечитывается на лету — `(load)` просто
заменяет определения функций.

Модуль `.NET` выгрузить без перезапуска нельзя, поэтому он намеренно
**тонкий**: в нём только то, чего нет в COM. Меняться ему почти не придётся,
а значит и перезапускать CAD — тоже. Это записано в
[ADR-0008](../docs/decisions/0008-own-dotnet-module.md) как правило, а не
как случайность.

## Если модуль .NET не собрался

Ничего страшного: команды работают и без него, только край области
картограммы считается приближённо, а не берётся у поверхности. `GCV`
покажет, загружен модуль или нет.

Разобраться:

1. Открыть `Contents\net\build.log` — там текст сборки.
2. Запустить `Contents\net\build.bat` вручную, чтобы увидеть сообщения.
3. Прислать этот текст — по нему видно, где встало.

Если `NETLOAD` ругается на безопасность: правой кнопкой по `GcSurface.dll` →
Свойства → галка «Разблокировать».
