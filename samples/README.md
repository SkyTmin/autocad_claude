# samples/ — реальные примеры входных данных

Здесь живут **реальные** файлы, на которых тестируется код. Без `samples/`
любой код пишется по догадкам — это нарушение R5 из Конституции.

## Структура

```
csv/    # Excel-выгрузки и подобное
txt/    # Выгрузки с тахеометров, нивелиров, GNSS
dwg/    # DWG-шаблоны, образцы итоговых чертежей
```

## Правила

1. **Только реальные данные** Шамиля или анонимизированные копии.
   Не придумываем структуру — берём как есть.
2. Если в файле есть **чувствительная информация** (адреса заказчиков, имена)
   — анонимизировать перед коммитом или хранить вне git (см. `.gitignore`).
3. Каждая фича опирается минимум на **один** файл из `samples/` соответствующей
   категории. Без этого — не пишем код.
4. Имена файлов: исходные имена пользователя сохраняем (даже если кириллица),
   чтобы при сравнении с реальной средой Шамиля не было разночтений.

## Что здесь сейчас

Пусто. Первые файлы добавит Шамиль при согласовании первой спеки.
