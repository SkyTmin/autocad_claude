# skills — Интеграционный страж проекта

> Этот скилл — **обязательное прохождение** перед запуском любого другого скилла,
> который пишет файлы. Цель — сохранить **один источник правды** для каждого типа
> сведений в проекте `autocad_claude`. Никаких параллельных файлов.

---

## 1. Зачем существует

AI-скиллы пишутся **не зная конвенций конкретного проекта**. Они создают
"стандартные" файлы (`.claude/settings.json`, `README.md`, `notes.md`,
`decisions.md`) даже если в проекте уже есть аналог под другим именем.
Результат — два файла с одной целью, путаница, регрессии.

Этот скилл — **карта интеграции**: для каждого типа артефакта указано
**ровно одно** место в проекте, где он живёт.

---

## 3. Протокол перед запуском другого скилла

Когда Шамиль говорит "запусти `/X`" или "сделай через `/X`":

1. **Прочитать** этот файл (`.claude/skills/skills/SKILL.md`) полностью.
2. **Прочитать** описание целевого скилла `/X`. Если описание говорит
   "пишу в `<file>`" — найти `<file>` в карте §2.
3. **Если в карте есть правило** — направить вывод скилла в указанное место,
   а **не в дефолтный путь скилла**.
4. **Запустить** целевой скилл.
5. **Проверить** что он не создал файлов вне карты. Если создал —
   слить в нужное место и удалить дубликат.
6. **Записать** в `status/PROGRESS.md` одну строку:
   `<дата>: запущен /X — вывод интегрирован в <file>`.
7. **Сообщить Шамилю** что и куда легло.

---

## 4. Если в карте нет нужного правила

**Не угадывай**. Используй `AskUserQuestion`:

> "Скилл `/X` хочет создать `<file>` для `<цель>`. В карте интеграции
> (`/skills` §2) такого правила пока нет. Куда положить — `<вариант-1>` или
> `<вариант-2>`? Я добавлю правило в карту после твоего ответа."

После ответа — **обязательно** добавить новую строку в §2 этого файла
и закоммитить.

---

## 5. Жёсткие инварианты

Эти правила **не нарушаются никогда**:

- **И-1: Один файл = одна цель.** Никаких `settings.json` рядом с
  `settings.local.json`. Никаких `notes.md` рядом с `HANDOFF.md`.
  Никаких `architecture.md` рядом с `docs/decisions/`.
- **И-2: Расширяй, не плоди.** Новая категория сведений → сначала вопрос
  Шамилю, потом строка в карте, **только потом** новый файл.
- **И-3: Карта — единственный авторитет.** Если карта говорит "сюда" —
  кладёшь сюда. Дефолтные пути скиллов **проигрывают** карте.
- **И-4: Удаление дублей разрешено** только если содержимое полностью
  слито в правильное место и Шамиль уведомлён.

## 6. Как этот скилл расширять

При появлении нового типа артефакта в проекте:

1. Добавить строку в §2 (Карту интеграции).
2. Если нужно — обновить ссылки в `CLAUDE.md` §9 (Карта проекта).
3. Закоммитить с сообщением `docs(skills): добавлено правило для <X>`.
4. Запушить на `claude/autocad-knowledge-hyVpn`.
